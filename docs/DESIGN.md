# کشاورز فقیر — تصمیم‌های طراحی

این فایل ثبت همه‌ی ابهام‌هایی است که با تصمیم منطقی حل شده‌اند (قانون طلایی ۸). هر تصمیم جدید اینجا اضافه می‌شود.

## تصمیم‌ها

| شماره | موضوع | تصمیم | دلیل |
|---|---|---|---|
| D01 | نام ریپو | ریپوی موجود `amirrezahadipoor/poor-farmer` به‌عنوان ریپوی اصلی استفاده می‌شود | کاربر دستور پوش به همین ریپو داده؛ نام `keshavarz-faghir` در نقشه‌ی راه صرفاً نمونه بوده است |
| D02 | نسخه‌ی جایگزین ROADMAP | فایل `ROADMAP.md` قبلی در ریپو (نسخه‌ی AMBERFIELD/Godot) با نسخه‌ی ارسالی کاربر جایگزین شد | نسخه‌ی ارسالی کاربر «تنها منبع حقیقت» اعلام شده و با آن نسخه تناقض کامل دارد |
| D03 | ابزارهای بیلد | `gradle-wrapper.jar` و توزیع‌های دانلودشده (Gradle، AGP، Android SDK) ابزار بیلد محسوب می‌شوند و مشمول ممنوعیت «فایل غیرکد» نمی‌شوند | ممنوعیت مربوط به دارایی بازی (تصویر، مدل، صدا) است؛ بدون ابزار بیلد ساخت APK ممکن نیست |
| D04 | رشته‌های حاوی `//` | هیچ رشته‌ی Java شامل `//` یا `/*` نمی‌شود (مثلاً URL ذخیره نمی‌شود) تا اسکنر کامنت خطا ندهد | سازگاری با `check_no_comments.sh` |
| D05 | تفکیک ماژول | `:core` (Java خالص، بدون وابستگی اندروید) برای منطق و تست واحد؛ `:app` برای رندر، رابط و صدا | قانون «منطق کاملاً جدا از رندر و قابل تست واحد» |
| D06 | پکیج پایه | `com.poorfarmer` با زیرپکیج‌های `core`، `render`، `world`، `entity`، `farm`، `animal`، `craft`، `economy`، `debt`، `story`، `ui`، `audio`، `save`، `data` | مطابق ساختار پکیج‌های بخش ۱ |
| D07 | نسخه‌های بیلد | compileSdk 36، targetSdk 36، minSdk 24، AGP 8.13.2، Gradle 8.14.5، JDK 17 | targetSdk آخرین پایدار (اندروید ۱۶)؛ AGP 8.x آخرین سری پایدار شناخته‌شده |
| D08 | API سطح پایین | APIهای بعد از ۲۴ اندروید بدون desugaring استفاده نمی‌شوند (مثلاً `List.of` در مسیر اجرای minSdk 24) | ساده‌نگه‌داشتن زنجیره‌ی بیلد؛ desugaring اضافه نمی‌شود |
| D09 | جهت صفحه | `SENSOR_LANDSCAPE` | قانون «فقط جهت افقی» |
| D10 | فونت فارسی | فونت سیستم دستگاه برای متن فارسی (بدون فونت داخلی) | قانون طلایی ۳ فایل فونت خارجی ممنوع است؛ فونت‌های سیستم اندروید فارسی را پشتیبانی می‌کنند |
| D11 | مدل زمان | هر روز بازی = ۴۸۰ ثانیه (۰۶:۰۰ تا ۰۲:۰۰)؛ ساعت بازی = ۱/۲۰ ثانیه واقعی؛ هر فصل ۱۴ روز؛ هر سال ۵۶ روز | بخش ۱ مشخصات فنی |
| D12 | ذخیره | JSON با فیلد `version`، ۳ اسلات دستی + ۱ اتوسیو (پایان هر روز و صحنه‌ی مهم)، نوشتن اتمیک با rename | بخش ۱ مشخصات فنی |
| D13 | ریاضی و رندر | ماتریس‌ها به‌صورت `float[16]` ستون‌اول (سازگار با OpenGL)؛ `Vec2/Vec3/Vec4/Quat` سبک بدون وابستگی اندروید در `:core` | قابل تست واحد بدون GL |
| D14 | عدد نمایش | اعداد در رابط با `NumberFormat`/حروف فارسی (`۰-۹`) و جداکننده‌ی هزارگان `٬` | قانون طلایی ۶ |
| D15 | واحد پول | «تومان» به‌صورت عدد صحیح (long) بدون اعشار | سادگی محاسبه و نمایش |
| D16 | نقشه‌ی پکیج/ماژول | پکیج‌های `core`،`world`،`farm`،`animal`،`craft`،`economy`،`debt`،`story`،`save`،`data`،`entity` (بخش خالص) در `:core`؛ `render`،`ui`،`audio` و `app` در `:app`؛ همه زیر `com.poorfarmer` | منطق قابل تست بدون اندروید |
| D17 | تأیید آیتم‌های GL | کلاس‌های مستقیم OpenGL (ShaderProgram، Mesh GL، پست‌پروسیس و…) با بیلد + lint + تست منطق خالص جانبی تأیید می‌شوند؛ تأیید بصری روی دستگاه با ابزار capture فاز ۱۱ | در این محیط شبیه‌ساز/دسترسند وجود ندارد؛ ساختار بیلد طوری است که هر خطای GL در اولین اجرا روی دستگاه فوراً معلوم می‌شود (RenderException با info log کامل) |
