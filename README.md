# کشاورز فقیر — Poor Farmer

شبیه‌ساز مزرعه‌ی داستان‌محور ۲.۵بعدی برای اندروید. تمام‌نشان (تمام‌فارسی، RTL)، کاملاً آفلاین، بدون تبلیغ و خرید درون‌برنامه‌ای. همه‌ی مدل‌ها، تکسچرها، صداها و موسیقی با کد ساخته می‌شوند؛ هیچ فایل رسانه‌ای خارجی وارد پروژه نمی‌شود.

- موتور: Java 17 + OpenGL ES 3.0 (بدون موتور بازی و بدون کتابخانه‌ی خارجی)
- داستان: سامان کیانی، ۵ سال تا تسویه‌ی بدهی ۹۰۰ میلیونی مزرعه‌ی ارث‌برده در روستای سرچشمه

## نقشه‌ی راه و وضعیت

فایل واحد برنامه‌ریزی: [ROADMAP.md](ROADMAP.md) — هر مورد با تیک یعنی پیاده‌شده و سبز.
وضعیت لحظه‌ای ساخت: [docs/STATE.md](docs/STATE.md)
داستان و دیالوگ‌های عین: [STORY_AND_DIALOGUES.md](STORY_AND_DIALOGUES.md)

## ساختار

- `app/` — اپلیکیشن اندروید: رندر (render)، رابط (ui)، صدا (audio)، چسب‌کاری lifecycle
- `core/` — منطق بازی خالص Java: جهان، مزرعه، دام، فرآوری، اقتصاد، بدهی، داستان، ذخیره، داده
- `assets/data/` — داستان و داده‌ی بازی به JSON
- `tools/` — شبیه‌ساز تعادل `BalanceSim.java`
- `scripts/` — اسکریپت‌های کنترل کیفیت
- `docs/` — طراحی، وضعیت و تعادل

## بیلد

نیازها: JDK 17، Android SDK (compileSdk 36).

```
./gradlew build
./gradlew :core:test
```

APK خروجی: `app/build/outputs/apk/debug/app-debug.apk`

## بازی‌کردن

جهت افقی. صفحه‌ها: منوی اصلی (انتخاب اسلات) → مزرعه با HUD و صفحات. هدف: تسویه‌ی کامل بدهی ۹۰۰ میلیون تومان در ۵ سال بازی و رسیدن به ثروت خالص ۲٫۵ میلیارد تومان.
